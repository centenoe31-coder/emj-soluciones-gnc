# EMJ SOLUCIONES GNC — Landing page

Proyecto educativo de una página web estática para una empresa de inspección y mantenimiento de instalaciones del sector energético, con foco en estaciones de servicio GNV y carretas de GNC.

## Estructura

- `index.html`: contenido y estructura semántica HTML5.
- `css/styles.css`: diseño visual, selectores CSS, Flexbox, Grid y media queries.
- `js/script.js`: menú móvil, validación de demostración del formulario y año automático.

## Cómo abrir el proyecto

1. Descarga y descomprime el ZIP.
2. Abre la carpeta `EMJ SOLUCIONES GNC_landing` desde Visual Studio Code.
3. Abre `index.html` en el navegador. Recomendado: instalar la extensión **Live Server** en VS Code y pulsar **Go Live**.
4. Edita los archivos y guarda para ver los cambios.

## Formulario

El formulario es solo una demostración del lado del navegador. Comprueba campos obligatorios y muestra un mensaje, pero no almacena ni envía información. Para recibir solicitudes reales, debe conectarse a un backend o servicio de formularios y publicarse con una política de privacidad adecuada.

## Nota sobre normas técnicas

La página menciona NTP 111.019 y NTP 111.042 como referencias indicadas para el negocio. Antes de publicar afirmaciones de cumplimiento, certificación o inspección acreditada, valida el alcance, edición vigente y requisitos aplicables con un profesional competente y las fuentes oficiales correspondientes.
